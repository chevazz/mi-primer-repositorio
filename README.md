##  Descripción del Proyecto
**SIGEVI** es una aplicación orientada a bodegas y minimarkets familiares de la ciudad de Oxapampa. El sistema automatiza el control de ventas, compras e inventario en tiempo real, procesa ventas en el punto de venta (POS) y emite boletas de venta rápidas, eliminando los errores de cálculo manual.

---

##  Objetivos del Sistema
- **General:** Registrar, controlar y gestionar de forma eficiente el inventario y ventas cotidianas en un negocio familiar.
- **Específicos:**
  - Control de stock dinámico con descuento automático en cada venta.
  - Alertas visuales de stock mínimo para reposición oportuna.
  - Gestión de roles de acceso (Administrador y Vendedor).
  - Generación de reportes inmediatos de rendimiento comercial.

---

##  Módulos Principales del Sistema
1. **Punto de Venta (POS):** Búsqueda por código de barras/nombre, carrito interactivo y cálculo de IGV.
2. **Inventario:** Tabla interactiva de productos, alertas de stock mínimo y formulario CRUD de creación/edición.
3. **Entrada de Compras:** Registro de facturas de ingreso para actualización automática de stock.
4. **Proveedores:** Catálogo de contactos de distribuidoras de la zona.
5. **Reportes:** Muestreo de ganancias totales, conteo de transacciones y tabla de historial de ventas.
